ShotbyUG Invoice Generator

Overview

A Python application designed to simplify invoice generation for freelance videography services.

The project aims to automate the creation of professional PDF invoices and reduce repetitive administrative work.

Planned Features

* Generate PDF invoices.
* Enter client and service details.
* Calculate deposits and outstanding balances.
* Include customised payment terms.
* Validate invoice information.

Technologies

* Python
* ReportLab

Project Status

In development. Features will be implemented and tested incrementally as the project progresses.
